# Quiet Room · 静室

为多动症与焦虑设计的小游戏合集——慢节奏、无压力、可暂停。

## 内容

- **耳语编年** (`identity-puzzle.html`) — 多章节身份推理游戏，黑色幽默剧情
- **数字花园** (`number-garden.html`) — 凑数运算解压游戏
- **解压小屋** (`relax.html`) — 触屏互动放松场景

## 设计原则

- 无计时、无失败惩罚
- 进度自动保存（localStorage）
- 暗色低刺激配色
- 适合 ADHD 和焦虑用户

## 部署

纯静态网站，无后端。任何静态托管都可以：
- Vercel: 直接连 GitHub 仓库
- Netlify: 同上
- GitHub Pages: 仓库设置里启用

所有 HTML 都是单文件（含 CSS + JS），无外部依赖。
